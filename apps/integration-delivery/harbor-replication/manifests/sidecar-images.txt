# whose image isn't from this cluster's Harbor - including Gatekeeper-
# injected sidecars, since validation runs after mutation - so these public

#

# not "**" like the app-repo replication - these rarely change and a
# surprise upstream tag move shouldn't silently alter what every tenant pod
# runs.
